Looking ahead

3-day outlook

What am I looking for? A low deck, clear sky above, calm air.

A “sea of clouds” needs a temperature inversion: cool, moist air trapped in the valley under a warmer layer aloft. The cloud deck tops out below the summit, the sky above is clear, and the wind is light enough not to mix the layers together.

This app compares the summit with a nearby valley town, checks the mid- and high-cloud cover, and scores every hour. The best window is usually from first light until mid-morning. After that, the sun often burns the deck away.

Forecasts are uncertain. A score of 80 is a strong hint, not a promise. Check the sky, the webcams, and your own judgment before you commit.

Alerts

Get a push when a good window is coming — 30 hours ahead by default. The alert is sent by a GitHub Action in your copy of the repo, so you only need to set this up once.

Tap the sparkle to generate a private topic, then install the free ntfy app and subscribe to it.

One-time setup

Add NTFY_TOPIC as a repository secret (or use the Telegram secrets below). The included GitHub Action checks every 15 minutes and sends the alert. See the README for the walkthrough.

Prefer Telegram?

Add TELEGRAM_BOT_TOKEN and TELEGRAM_CHAT_ID as repository secrets instead. The same action will use Telegram. Create a bot with @BotFather, send it a message, then read your chat ID from api.telegram.org/bot<token>/getUpdates.

iPhone home-screen widget

Home-screen widgets show the Bay’s ranked windows: small shows 3 peaks, medium shows 4 plus a 3-day pulse, and large shows 7 plus a richer pulse. Tap any widget to open the full 38-peak list.

  1. Install Scriptable (free).
  2. Tap Copy widget script below, create a new script in Scriptable, and paste.
  3. Long-press the home screen → Add Widget → Scriptable → choose the small, medium, or large size.
  4. Lock-screen widgets still show one peak; set their parameter to a peak ID such as mount-tamalpais.

The copied script already points at this site. If copying is blocked, open the raw file and set APP_URL by hand.

About

Above the Clouds scores the marine-layer inversion for Bay Area peaks. It uses the free Open-Meteo forecast API and runs entirely in your browser. No account, no tracking.

Forecasts can be wrong. This is a planning aid, not a safety device. Check the weather, trail conditions, and your own eyes before you go.
